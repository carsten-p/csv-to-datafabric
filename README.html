CSV → Data Fabric

Turns any CSV file into a UiPath Data Fabric entity and loads its rows, using the uip CLI. Two versions with the same behaviour: PowerShell for Windows, Node.js for macOS, Linux and Windows.

What it does

  1. Reads the CSV – detects delimiter (, ; TAB |) and encoding; handles quotes, line breaks in values, empty or duplicate headers.
  2. Fixes the column names to Data Fabric's rules. The original header stays visible as the display name.
  3. Picks a type per column from all rows: number, yes/no, date, date-time or text. Values with leading zeros (postcodes) stay text.
  4. Shows the plan and asks – field types can't be changed after creation.
  5. Creates the entity and loads the rows in chunks. Rows with line breaks in a value are inserted separately, so nothing is lost.

Before you start

  • UiPath CLI installed and logged in: uip login
  • Data Fabric tool: uip tools install @uipath/data-fabric-tool@latest
  • Folder-scoped entity? Get the folder key: uip or folders get "Shared" --output json → Key

Quick start

Windows · PowerShell

Preview first, then run:

.\Import-CsvToDataFabric.ps1 -CsvPath .\data.csv -DryRun
.\Import-CsvToDataFabric.ps1 -CsvPath .\data.csv

macOS / Linux / Windows · Node.js

Preview first, then run:

node import-csv-to-datafabric.mjs ./data.csv --dry-run
node import-csv-to-datafabric.mjs ./data.csv

How column names are fixed

Data Fabric field names allow only letters and digits, must start with a letter and be 3–100 characters.

Straße & Hausnr.StrasseHausnrUmlauts replaced, punctuation removed

Good to know

  • Preview with -DryRun first. Types are permanent; fix them with -ColumnTypes before creating.
  • No row limit in the script. Rows are uploaded in chunks of 5,000. The whole file is read into memory.
  • An existing entity is never overwritten. Same name → the script stops. -UseExisting adds rows (re-running duplicates them).
  • Windows blocks the downloaded script? Run Unblock-File .\Import-CsvToDataFabric.ps1 once.
  • Not in a terminal (scheduled task, pipeline)? Add -Force / --force.
  • Result: a summary with inserted rows and links to error files. Node prints it as JSON on stdout.
